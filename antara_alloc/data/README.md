# data/
- `raw/` immutable downloads + `manifest.json` (source, tickers, timestamps, sha256, rows).
- `processed/` cleaned parquet. Only `scripts/split.py` reads it.
- `training/` ≤ 2019-12-31. Access only through `common.data_access.TrainingLoader`.
- `test_holdout/` ≥ 2020-01-01. LOCKED (chmod 000). Only `common/run_holdout.py` may open it.
- `scripts/` pipeline: `download.py` → `build_processed.py` → `split.py`. Split refuses to run again once locked.

**In this repository:** only `scripts/`, `membership/sp500_membership.csv` and `reference/` (the candidate pool and the S&P 500 changes table used to build the membership file) are stored in git. `raw/`, `processed/`, `training/` and `test_holdout/` are generated by the scripts and are git-ignored.
